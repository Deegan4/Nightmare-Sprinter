# reference-source (private, not committed)

Put the owner's downloaded manual PDFs here. Everything in this folder except
this README is ignored by git (see `.gitignore`).

- 2011-2019 Sprinter wiring set (cardiagn.com watermark)
- Mercedes-format wiring / fuse / ground set (truckfixdiagn.com)

These are third-party manuals. Do not publish them, commit them, or serve them
from a public URL. Use `scripts/pdf-to-images` to upload page images to the
private R2 bucket; the app only serves them to signed-in members.

Do NOT add the earlier AI-generated "wiring diagram" infographic. It had invented
fuse numbers and layout and must not appear anywhere in the app.
